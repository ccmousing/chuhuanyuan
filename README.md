# 「出花园」潮汕成人礼文化小程序

> 从一项省级非遗的地方民俗，到一套可执行的小程序方案、验证原型，以及一个可溯源的民俗问答技术方案。

「出花园」是潮汕地区独有的成人礼俗，2018 年入选广东省第七批省级非物质文化遗产名录。
本项目针对「它只活在长辈口述与每年一次的线下活动里」这一现状，设计了一套面向
**泛文化爱好者/游客、中小学生研学群体、本地家长家庭** 三类用户的数字产品方案。

## 项目方法论（可复用于同类地方文化项目）

1. **事实核实** — 两轮检索：文化本体（由来/流程/符号/典故/非遗认定）+ 活化现状（各地官方做法、海外传播、已有线上化先例）
2. **需求分层** — 明确目标用户、核心定位、投入规模与交付范围，全部落到书面确认
3. **架构设计** — 信息架构 → 功能分层（明确每期**不做什么**）→ 用户旅程 → 技术架构
4. **原型验证** — 用可点击原型暴露结构问题，而不是交付静态稿

## 文化严谨性说明

- 涉及地方差异的民俗细节（十二种花草名目、十二碗菜品、择吉月份等）**统一标注「各地略有差异」**
- 标注「需进一步核实」的内容，正式上线前须经文化馆或民俗专家审校
- 民间传说与史实分开标注，不把传说当史实
- 汕潮揭三地共享此民俗，内容采用**等权重并列呈现**，标题不冠单一城市名
- 文化依据来源：广东省/汕头市非遗名录公开信息，汕潮揭三地官方「出花园」成人礼活动公开报道，主流媒体（人民日报海外版、中国文明网、广东文明网等）专题报道

## 开发与提交约定

- 若实现 RAG 模块，API Key 一律放在 `.env` 中并加入 `.gitignore`，仓库内只保留 `.env.example` 占位模板
- 知识库条目的 `source` 字段不得为空；无来源的条目不得收录
- **推送前先自查密钥**：`git ls-files | grep -Ei "\.env|key|token|secret"`，有命中就先清理再推
- 小程序代码包口径：`miniprogram/` 下排除 `.git/`、`*.md`、`project.private.config.json` 后约 **110 KB**（上限 2 MB）

## 怎么发布成在线链接（GitHub Pages）

仓库根就在本目录，而 `index.html` 就在根目录 —— 所以**不用配构建，开一下 Pages 就有在线地址**：

1. 把本目录推到 GitHub（仓库根 = 本目录，不要再套一层）
2. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` / 目录选 `/ (root)` → 保存
3. 等约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`，就是**策划方案站**
   - `.../prototype.html` → 7 屏可点击原型
   - `.../case-study.html` → 案例研究主页
   - `.../deploy-guide.html` → 上线实操路线图

投简历或参赛时直接给对方这个 URL，比发文件方便得多。

> 仓库根放在本层而不是 `miniprogram/`，主要就是为了这一步 —— 小程序源码作为子目录一起版本化，同时 HTML 交付物能直接对外发布。
