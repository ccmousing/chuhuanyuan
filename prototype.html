「一枝今已出花园」

出花园是潮汕地区独有的成人礼俗，由古代冠笄之礼演变而来。潮汕人认为十五虚岁前孩子受「公婆母」庇佑，生活在花园里；举行出花园仪式，即拜谢神恩、跨出花园墙，正式成人。

这套原型演示了什么

  • 完整用户旅程：从「看懂」→「玩到」→「约上」→「留下」
  • 三类用户各有关口：游客看科普、学生玩闯关、家长走预约
  • 唯一天然带传播的功能是祝福卡 + 纪念证书，是 MVP 的增长支点

怎么操作

  • 点上方 ①–⑦ 切换屏
  • 点手机内的入口（四宫格 / 社区横幅 / 列表项）可跳转
  • 底部 Tab 固定「首页 / 文化 / 体验 / 我的」四项
  • 「七步仪式」可上下步切换；「知识闯关」可点选答案看解析

与方案的对应

  • ①首页 → 功能分层图 MVP 层
  • ②文化馆 → 内容分级「成年版/深读」
  • ③七步仪式 → 文化知识库 2.3 节
  • ④闯关 → 内容体系 4.3 题库
  • ⑤预约 → V2 期服务闭环
  • ⑥社区 → V2 期 UGC 与审核
  • ⑦我的花园 → 用户旅程「传播」段
