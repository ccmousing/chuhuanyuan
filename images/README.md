# 素材目录 · 知识科普配图

**换图只需要动这个文件夹，不用改任何代码。**

---

## 一、命名规则（唯一要记的事）

```
images/<文章 id>.jpg
```

文件名（不含扩展名）必须和下面这张表完全一致。

**扩展名支持 `.jpg` / `.png` / `.webp`** —— 三种都行，不用手动转格式。
代码会按 jpg → png → webp 的顺序依次尝试，命中哪个用哪个。

| 文件名 | 对应文章 | 用在哪 |
|---|---|---|
| `what-is.jpg` | 出花园到底是什么？ | 文化馆 / 收藏 / 记录 / 延伸阅读 |
| `why-clogs.jpg` | 为什么出花园要穿红木屐？ | 首页编辑推荐 / 文化馆 / 收藏 / 记录 |
| `twelve-flowers.jpg` | 十二花水，到底是哪十二种花？ | 同上 |
| `head-dish.jpg` | 头彩食十二碗，每碗都有彩头 | 同上 |
| `gongpopo.jpg` | 公婆母是谁，为什么要拜？ | 同上 |
| `three-cities.jpg` | 汕潮揭三地，办得哪里不一样 | 同上 |

**没放图的文章会自动回退到原来的 emoji + 色块**，不会出现空白或报错。所以可以一张一张慢慢换。

> 注意：同一篇文章只需放**一种**格式。如果同时存在 `why-clogs.jpg` 和 `why-clogs.png`，优先用 jpg。

## 二、图片规格

| 项 | 建议值 | 说明 |
|---|---|---|
| 尺寸 | **208 × 208 px** | 显示尺寸是 104rpx × 104rpx，2 倍图刚好清晰 |
| 比例 | **1:1 正方形** | 用 `aspectFill` 裁切，非正方形会裁掉边缘 |
| 格式 | JPG / PNG / WebP | 三种都支持，按 jpg → png → webp 依次尝试 |
| 单张体积 | **≤ 30 KB** | 6 张控制在 200 KB 内 |
| 内容 | 主体居中偏上 | 缩略图很小，细节多会糊成一团 |

⚠️ **微信代码包上限 2MB**，当前已用 166 KB。6 张图按 30 KB 算约 180 KB，占 9%，安全。如果每张做到 100 KB 就要注意了。

---

## 三、怎么换

1. 把新图裁剪成 **1:1 正方形**
2. 导出为 JPG / PNG / WebP 均可，单边 208px 左右
3. 改成上表对应的文件名
4. 覆盖到本文件夹
5. 开发者工具里点「编译」

就这五步，**不需要动 `content.js`、不需要动 wxml**。

---

## 四、命名怎么来的

文件名用的是 `miniprogram/utils/content.js` 里每篇文章的 `id`：

```js
{ id: 'why-clogs', title: '为什么出花园要穿红木屐？', ... }
```

wxml 里直接拼路径：`src="/images/{{item.id}}.jpg"`。
所以是「文件名对上了就生效」，代码里没有一张图的清单需要同步维护。

## 五、不在这里的东西

| 素材 | 位置 | 说明 |
|---|---|---|
| tabBar 4 个图标 | `custom-tab-bar/index.wxss` | data-URI SVG，**不要换成图片**（会变糊、变重） |
| 石榴花装饰 | 各页面 wxss（纯 CSS 画） | 同上，CSS 画的更清晰 |
| 祝福卡导出图 | 运行时生成 | 不是素材，是 canvas 绘制 |
| 祝福卡 12 条文案 | `utils/blessing-copy.js` | 文字不是图 |

## 六、版权提醒

非遗类配图有两个风险叠在一起：**版权** + **文化尊重**（用错图、用丑图会被当地人视为不敬）。三条合法路径：

1. **自己拍** —— 最真实，尤其是仪式用品、老厝细节
2. **文化馆授权** —— 顺带拿到「官方审校」背书
3. **CC0 / 明确可商用图库** —— 但潮汕民俗专属素材很难找到合适的

**不要从网上随便搜图直接放进来。**
