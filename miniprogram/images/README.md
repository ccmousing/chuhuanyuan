# 素材目录 · 知识科普配图

**换图只需要动这个文件夹，不用改任何代码。**

> **当前状态（2026-11-02）**：6 张已全部配齐，AI 生成，合计 **39.7 KB**（单张 3.9–8.3 KB）。生成方式与重跑命令见第七节。

---

## 一、命名规则（唯一要记的事）

```
images/<文章 id>.jpg
```

文件名（不含扩展名）必须和下面这张表完全一致。

**扩展名支持 `.jpg` / `.png` / `.webp`** —— 三种都行，不用手动转格式。
代码会按 jpg → png → webp 的顺序依次尝试，命中哪个用哪个。

| 文件名 | 对应文章 | 用在哪 |
|---|---|---|
| `what-is.jpg` | 出花园到底是什么？ | 文化馆 / 收藏 / 记录 / 延伸阅读 |
| `why-clogs.jpg` | 为什么出花园要穿红木屐？ | 首页编辑推荐 / 文化馆 / 收藏 / 记录 |
| `twelve-flowers.jpg` | 十二花水，到底是哪十二种花？ | 同上 |
| `head-dish.jpg` | 头彩食十二碗，每碗都有彩头 | 同上 |
| `gongpopo.jpg` | 公婆母是谁，为什么要拜？ | 同上 |
| `three-cities.jpg` | 汕潮揭三地，办得哪里不一样 | 同上 |

**没放图的文章会自动回退到原来的 emoji + 色块**，不会出现空白或报错。所以可以一张一张慢慢换。

> 注意：同一篇文章只需放**一种**格式。如果同时存在 `why-clogs.jpg` 和 `why-clogs.png`，优先用 jpg。

---

## 二、图片规格

| 项 | 建议值 | 说明 |
|---|---|---|
| 尺寸 | **208 × 208 px** | 显示尺寸是 104rpx × 104rpx，2 倍图刚好清晰 |
| 比例 | **1:1 正方形** | 用 `aspectFill` 裁切，非正方形会裁掉边缘 |
| 格式 | JPG / PNG / WebP | 三种都支持，按 jpg → png → webp 依次尝试 |
| 单张体积 | **≤ 30 KB** | 6 张控制在 200 KB 内 |
| 内容 | 主体居中偏上 | 缩略图很小，细节多会糊成一团 |

⚠️ **微信代码包上限 2MB**，当前约 206 KB（含 6 张图）。6 张图合计 39.7 KB，占 2%，余量充足。如果以后换成实拍大图，注意单张别超过 100 KB。

---

## 三、怎么换

1. 把新图裁剪成 **1:1 正方形**
2. 导出为 JPG / PNG / WebP 均可，单边 208px 左右
3. 改成上表对应的文件名
4. 覆盖到本文件夹
5. 开发者工具里点「编译」

就这五步，**不需要动 `content.js`、不需要动 wxml**。

---

## 四、命名怎么来的

文件名用的是 `miniprogram/utils/content.js` 里每篇文章的 `id`：

```js
{ id: 'why-clogs', title: '为什么出花园要穿红木屐？', ... }
```

wxml 里直接拼路径：`src="/images/{{item.id}}.jpg"`。
所以是「文件名对上了就生效」，代码里没有一张图的清单需要同步维护。

## 六、版权提醒

非遗类配图有两个风险叠在一起：**版权** + **文化尊重**（用错图、用丑图会被当地人视为不敬）。三条合法路径：

1. **自己拍** —— 最真实，尤其是仪式用品、老厝细节
2. **文化馆授权** —— 顺带拿到「官方审校」背书
3. **CC0 / 明确可商用图库** —— 但潮汕民俗专属素材很难找到合适的

**不要从网上随便搜图直接放进来。**

## 七、本轮 6 张图怎么来的（2026-11-02）

全部由 AI 生成，统一风格：暖米白底（#FDF8F0）+ 砖红主色（#C8443C）+ 金色点缀，扁平矢量民俗插画，**无文字、无人物**（小尺寸下文字必糊，人物容易失真）。

| 原图（1024×1024） | 输出 |
|---|---|
| `assets/ai-gen/…13-33-24.png` | `why-clogs.jpg` |
| `assets/ai-gen/…13-34-01.png` | `what-is.jpg` |
| `assets/ai-gen/…13-34-17.png` | `twelve-flowers.jpg` |
| `assets/ai-gen/…13-34-32.png` | `head-dish.jpg` |
| `assets/ai-gen/…13-34-47.png` | `gongpopo.jpg` |
| `assets/ai-gen/…13-35-02.png` | `three-cities.jpg` |

原图在项目根 `assets/ai-gen/`（约 8.5 MB，**在小程序仓库之外**，不会占代码包）。换图后重跑一次即可：

```bash
python tools/prep-images.py
```

脚本做三件事：居中裁正方形 → 缩到 208×208 → JPEG q82 输出。

⚠️ **AI 图的局限**：细节不一定经得起民俗考据（木屐形制、供品种类都可能不准）。当前用于演示阶段没问题，**上线前仍建议按第六节换成文化馆审校过的实拍图**。

## 八、仪式用品小图（`images/sym/`）

文化馆「文化符号图鉴」六宫格用的图，**独立子目录、独立命名**，不影响上面的文章配图规则。

| 文件 | 对应符号 |
|---|---|
| `sym/clogs.jpg` | 红木屐 |
| `sym/pomegranate.jpg` | 石榴花 |
| `sym/flower-water.jpg` | 十二花水 |
| `sym/rooster.jpg` | 公鸡 |
| `sym/peach-cake.jpg` | 红桃粿 |
| `sym/waistband.jpg` | 腰兜 |

规格：

- **200 × 200 px**，JPEG，单张 ≤ 40 KB（当前 6 张合计 34 KB）
- 显示尺寸 104rpx × 104rpx（`aspectFit`），方形图最稳
- **必须白底**：卡片本身是 `#FFFFFF`，图与卡同色才没有色块边界；不要放透明 PNG，也不要放带场景背景的图
- 换图后重跑：`python tools/prep-symbols.py`（会做「背景压白 → 裁方 → 缩到 200 → JPEG」）

命名与 `culture.js` 里 `symbols[].img` 字段对应；对不上会**静默回退 emoji**，所以改完记得跑 `node tools/check-images.js`（F 段会校验这 6 张）。加载失败也有兜底（`onSymErr` → emoji），不会出现破图。
